# Organic Chemistry II, Bio-organic Edition
A second-semester course in organic chemistry with applications to biochemistry. Video lectures can be found in [this playlist](https://www.youtube.com/playlist?list=PLykBd3LSjfsTPbhbIujp909K-HPkrS8P7). Video lectures are based on the third edition of _Organic Chemistry_ by Klein, but any edition of this textbook can be used without major issues. It's also possible to follow along using McMurry's [_OpenStax Organic Chemistry_](https://openstax.org/details/books/organic-chemistry) textbook here. Course topics and their associated chapters in each book can be found below.
